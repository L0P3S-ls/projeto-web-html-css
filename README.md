# Site Informativo Católico

## Sobre o projeto

Este projeto consiste em um site simples com temática católica, desenvolvido como atividade acadêmica para praticar e testar conhecimentos de programação e desenvolvimento web.

O site apresenta conteúdos relacionados à história, aos feriados e ao santuário, utilizando uma estrutura simples para organizar e apresentar as informações.

## Objetivo do projeto

O principal objetivo foi colocar em prática os conhecimentos adquiridos durante os estudos, experimentar o uso de diferentes códigos e desenvolver habilidades na criação de páginas web.

Este é um projeto de aprendizado, sem finalidade comercial ou proposta de utilização profissional.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome

## Estrutura do projeto

- `index.html` — página principal do site.
- `css/` — arquivos de estilização.
- `js/` — arquivos JavaScript.
- `img/` — imagens utilizadas no site.
- `fontawesome/` — arquivos de ícones.

## Como acessar o projeto

O site está publicado pelo GitHub Pages:

https://l0p3s-ls.github.io/projeto-web-html-css/

Para executar localmente:

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.

## Considerações finais

Este projeto representa uma etapa do meu aprendizado em desenvolvimento web, permitindo praticar conceitos, testar códigos e desenvolver minha experiência com HTML, CSS e JavaScript.
